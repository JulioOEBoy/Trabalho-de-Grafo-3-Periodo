## Sobre o Projeto

Este projeto foi desenvolvido como avaliação prática da disciplina de Estrutura de Dados do 3º período.

O sistema simula rotas entre diferentes pontos de uma cidade utilizando o algoritmo de Dijkstra para determinar o caminho com menor tempo de deslocamento entre dois locais.

Além do cálculo da melhor rota, a aplicação apresenta uma visualização gráfica do mapa, permitindo acompanhar de forma intuitiva o funcionamento do algoritmo e o impacto de diferentes condições de trânsito sobre o resultado.

---

## Funcionalidades

- Cálculo da melhor rota utilizando o algoritmo de Dijkstra.
- Exibição visual do grafo em um mapa interativo.
- Representação de diferentes condições das vias.
- Cálculo automático da distância total percorrida.
- Cálculo automático do tempo total de deslocamento.
- Destaque visual da rota escolhida pelo algoritmo.

## Legenda das Rotas

- 🟢 **Verde:** rota normal.
- 🟡 **Amarelo:** rota com trânsito (tempo aumentado).
- 🟠 **Laranja:** rota em obra (tempo aumentado).
- 🔴 **Vermelho:** rota bloqueada (não pode ser utilizada).
- 🔵 **Azul:** melhor rota encontrada pelo algoritmo.
